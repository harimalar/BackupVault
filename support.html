Email rajhari@gmail.com for help with BackupVault.

What to include

Your macOS version, BackupVault version/build, whether the destination is a local drive or NAS, and a short description of the problem. Do not send passwords. Review any logs or screenshots for personal paths and sensitive information before attaching them.

Backup in three steps

Choose folders, choose a destination, then select Back Up Now. Choices save automatically. Keep the app open for scheduled backups. More Options contains verification, exclusions, and optional cleanup/eject switches.

Network drive help

You may need to allow local-network access and connect to the server in Finder. If the app cannot list shares, enter the share name manually. macOS may ask you to authenticate. No network connection is needed for local drive backups.

Restore and drive safety

Test restoring a small file to a separate folder before relying on a backup. Restore can replace matching files. Wait for safe-eject confirmation before disconnecting a drive. If automatic eject reports an error, leave the drive connected and eject it using Finder.

Data removal

Removing a destination does not delete stored backups or local history/logs. Manage backups in Finder and saved credentials in Keychain Access. Email support for help locating the app's local settings and logs. Requests about support correspondence can be sent to the same address.
